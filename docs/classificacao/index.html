CARTEIRA

Classificar e liquidar

Carrega o pedido da Carteira para criar uma ligação, ou abre a ligação recebida para classificar os movimentos e preparar a resposta.

Privacidade

O pedido é lido neste navegador e os movimentos seguem dentro da ligação, sem serem enviados ao site. Qualquer pessoa com a ligação consegue ver os movimentos incluídos. A resposta contém apenas as escolhas.

Este passo é para quem enviou o pedido. Escolhe o ficheiro criado pela app; o conteúdo é validado e lido localmente.

Para cada despesa, só aparecem os orçamentos disponíveis indicados no pedido. As liquidações têm de igualar exatamente a receita.

Despesas

Liquidações

Seleciona despesas até o total ficar exatamente igual ao valor da receita. Uma despesa só pode pertencer a uma liquidação.

Escolhe pelo menos um orçamento ou uma liquidação válida.

A resposta é colocada numa ligação para enviares ao remetente; não é preciso descarregar nem carregar ficheiros.

Resposta pronta

Esta ligação contém apenas as escolhas feitas. Descarrega o JSON e importa-o em Movimentos → Resposta na Carteira.
